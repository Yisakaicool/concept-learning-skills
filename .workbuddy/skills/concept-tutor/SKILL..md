# 概念学习资料生成 Skill

## 适用场景
当用户需要快速理解一个陌生概念（特别是计算机科学、AI 领域）时，使用此 Skill 生成一份包含定义、机制、实例、边界和参考来源的学习笔记。

## 输入信息
用户需要提供：
- 概念名称（必须）
- 可选：背景说明或重点关注方向（例如“侧重于实际应用”）

## 生成步骤
1. 根据概念名称，搜索并汇总可靠资料（优先使用权威文档、论文、官方博客）。
2. 用通俗语言编写“个人解释”（200 字以内）。
3. 提炼“核心机制或组成”（列出关键组件或工作原理）。
4. 提供一个“具体应用场景”（真实或模拟）。
5. 指出“容易混淆的问题或使用边界”（与其他概念的区别，或局限）。
6. 列出“可核查的资料来源链接”（至少 2 个）。
7. 生成“自测问题”（3 个，帮助检验理解）。
8. 输出格式为 Markdown 或 HTML（由用户指定）。

## 输出结构
输出应包含以下章节（按顺序）：
- 概念名称
- 个人解释
- 核心机制/组成
- 具体应用场景
- 容易混淆的问题/边界
- 资料来源
- 自测问题

## 自检要求
- 确保解释无歧义，不照搬原文。
- 所有链接有效且可访问。
- 内容应足够独立，无需额外背景即可理解。
- 如果概念涉及多个子领域，应明确说明覆盖范围。
