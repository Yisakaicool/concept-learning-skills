# 概念学习 · Agent（智能体）

> 方法：故事概念导师（Story Concept Tutor）——「悟到 → 命名 → 印证」
> 学习日期：2026-09-04

---

## 一、先听一个故事（不点破概念）

**《守山人》**

老陈守着一座山上的气象站，山顶只有他一个人。入秋后，山下的护林办交给他一句话：**"赶在霜降前，让山顶营地能过冬。"** ——就这样，再没有第二条指令。

没人告诉他该怎么干。老陈站到院子里，抬头看天（天色发沉、云层压得低），蹲下身摸了摸土（已经有些潮），心里默默列了个清单：屋脊的瓦要压牢、柴要劈够、水缸要存满、被褥要添厚。

他转身回屋，拿出锯子和锤子——他手边没有"维修队"，只有一堆随手能用的家伙。腿脚不好的他，一趟一趟地搬瓦、劈柴、挑水。三天后，一场大风掀翻了两片瓦，他夜里摸黑爬上去又压好；第五天又降温，他把原本秋天才用的棉被提前翻出来。

霜降那晚，大雪灌下来，营地里的老陈，火炉正旺。他从头到尾，没有等谁来告诉他下一步——他**自己看见了缺什么、自己决定先做什么、用自己的工具去补，做完了再看效果调整**，直到那句"能过冬"变成现实。

---

## 二、你觉得这个故事在讲什么道理？

（这是关键一步——先自己说一说再往下读。想好了吗？）

一个合理的感悟方向大概是：*老陈不是被人一步步指挥着做，而是被交予一个目标，然后自己去看、去想、去动手、去调整，最终自主地把事情做成。*

---

## 三、揭晓：这个道理的名字

这个道理，在人工智能领域，有一个名字，叫 **Agent（智能体）**。

它的通俗本质是：**你给它一个目标，它自己负责"看、想、做、再回头看"，一步步把目标变成现实，而不是被动地等着你每步都下指令。**

---

## 四、对照映射

| 故事里的情节 | Agent 的核心要素 |
|---|---|
| 护林办只给一句"让营地能过冬"，再无指令 | **目标导向**：Agent 从"一个目标/指令"出发，而不是被逐步遥控 |
| 老陈抬头看天、摸土、心里列清单 | **感知（Perception）**：Agent 先感知环境与现状，弄清"差距在哪" |
| 他把目标拆成修瓦、劈柴、存水、添被 | **规划 / 任务分解（Planning）**：把大目标拆成可执行的小步骤 |
| 他拿起锯子、锤子，自己动手 | **行动 / 工具调用（Acting & Tool Use）**：用可用的工具去执行动作 |
| 瓦被掀翻他夜补、降温他提前翻棉被 | **反馈循环（Feedback Loop）**：观察结果、发现问题、自主调整再迭代 |
| 从头到尾没有等下一步指令 | **自主性（Autonomy）**：独立运转，直到目标达成为止 |

---

## 五、一句话收尾

所以 **Agent（智能体）的本质是**：以目标为起点，自主地"感知 → 规划 → 行动 → 反馈调整"循环，直到达成目标的一种智能系统。
